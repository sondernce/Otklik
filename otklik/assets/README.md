# Визуальные материалы

- `brand/otklik-original.jpeg` — точная копия логотипа из папки «Визуал исходники». Исходник сохранён без изменений. В шапке символ отображается через CSS-окно поверх исходного изображения; это не векторный мастер логотипа.
- `illustrations/conversation.svg` — созданная для сайта иллюстрация двух переплетающихся линий, вдохновлённая пластикой знака. Это иллюстрация, а не замена логотипа.

Все используемые картинки хранятся в этой папке, без внешних ссылок. Новые изображения распределяем по `brand/`, `illustrations/`, в будущем — `photos/`. Оригиналы пользователя остаются в «Визуал исходники».

- `illustrations/room.svg` — оригинальная векторная иллюстрация разговора для концепции «Личное пространство» (v0.6). Без заимствований фотографий и персонажей референсов. `conversation.svg` сохранена как материал предыдущего варианта, в текущей странице не используется.
