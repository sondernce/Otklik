# Проверка текущих сценариев

Проверены существующие функции без подключения почты, видеопровайдера и платежей. Использовались временные базы; пользовательский файл SQLite не изменялся. Оформление страниц сохранено.

## Исправления

| Ситуация | До исправления | Текущее поведение |
| --- | --- | --- |
| Список встреч загружается, пользователь выходит и входит в другой аккаунт в той же вкладке | Задержанный ответ мог вернуть записи прежнего аккаунта в кабинет нового пользователя | Ответы привязаны к текущему входу; после выхода данные встреч и календаря очищаются, устаревший ответ игнорируется |
| Несколько обновлений списка выполняются одновременно | Более ранний запрос мог заменить более свежий список | Применяется результат последнего обновления в текущем входе |
| Повторяется исходный запрос записи после нескольких переносов | Сервер сравнивал запрос с текущим временем встречи и возвращал конфликт | Исходное время определяется по истории первого переноса; возвращается существующая встреча с её текущим временем |
| Психолог открывает карточку уже начавшейся встречи | Редактор видеоссылки предлагался, хотя сервер запрещал её изменение | Редактор показывается только до начала, как и разрешено сервером; переписка остаётся доступной |

В клиентском кабинете очищаются карточки, календарь и поля настроек. В кабинете психолога очищаются записи, календарь и данные анкеты. Обработчики изменения записи проверяют актуальность входа перед применением результата. При повторном входе психолога поздние ответы на запросы прежнего аккаунта не заполняют анкету нового пользователя.

Исправление повтора записи использует существующую историю изменений. Новая миграция и изменение структуры базы не потребовались. Ключ прежнего запроса нельзя использовать с новым временем: такой изменённый запрос по-прежнему получает конфликт.

## Проверки

- `test_changes.py`: исходный запрос повторяется после двух автоматических переносов, сохраняется идентификатор встречи; изменённый запрос с тем же ключом отклоняется.
- `browser.test.cjs`: для клиента и психолога задерживается ответ о встречах, выполняются выход и вход в другой аккаунт; после доставки старого ответа записи прежнего аккаунта отсутствуют.
- `test_booking_controls.cjs`: редактор видеоссылки соответствует ограничениям сервера, доступ к переписке сохраняется, действия будущей встречи остаются доступными.

Полный набор также проверяет подбор и регистрацию, ручное и автоматическое подтверждение, отмену и переносы, повторную запись, переписку, поддержку, уведомления и сохранность данных. Браузерные сценарии выполняются в Chromium; проверка других браузеров и работа внешних сервисов остаются за пределами этой проверки.

Результат: прошли 96 серверных тестов, все 16 браузерных сценариев и обе клиентские проверки времени и действий карточки.
