# Почта: очередь и локальная проверка

Домен и почтовый сервис ещё не выбраны. Подготовлена техническая основа: очередь в SQLite, обработчик локальных писем и защищённого SMTP. Подтверждение адреса, восстановление пароля, письма о встречах и напоминания пока не подключены к событиям приложения. При обычной регистрации письма ещё не создаются, ограничения до подтверждения адреса не включены.

## Локальный режим

Команды выполняются из `otklik/`, путь должен указывать на отдельную тестовую базу:

```sh
python3 -B mail_worker.py --database /path/to/test.sqlite3 --status
python3 -B mail_worker.py --database /path/to/test.sqlite3
```

Обработчик выполняет один проход, до 20 писем; лимит можно изменить через `--limit` от 1 до 100. В режиме по умолчанию выбираются только задания с `transport='local'`. Письма сохраняются в `mail-preview/` рядом с выбранной базой. Это файлы `.eml`, которые можно открыть почтовой программой или текстовым редактором. Реальная отправка в этом режиме отсутствует. Если очередь пустая, письма не создаются.

Имена файлов определяются идентификатором задания. Файлы публикуются атомарно с правами `0600`, папка создаётся с `0700`. Повтор после остановки процесса не создаёт второй файл и не перезаписывает другой файл с тем же именем. Папка исключена из Git и не выдаётся HTTP-сервером. Файлы могут содержать адреса и секретные ссылки; для разработки используйте тестовые данные, удаляйте ненужные `.eml` вручную. Автоматическая очистка локальных файлов пока не добавлена.

После успешного формирования локального письма очередь имеет статус `preview`; это не отправка адресату. Тело, тема и получатель в строке очереди очищаются. Сам `.eml` остаётся для проверки.

## Подключение SMTP позже

Шаблон настроек находится в `.env.example` в корне проекта. Приложение не загружает `.env` автоматически: значения должны передаваться через окружение процесса. Настоящие пароли и ключи не помещать в Git и не присылать в чат.

| Переменная | Назначение |
| --- | --- |
| `OTKLIK_MAIL_FROM` | Один адрес отправителя без отображаемого имени |
| `OTKLIK_SMTP_HOST` | SMTP-сервер выбранного сервиса |
| `OTKLIK_SMTP_PORT` | Порт, по умолчанию 465 для SSL или 587 для STARTTLS |
| `OTKLIK_SMTP_SECURITY` | `ssl` или `starttls`; незашифрованный режим отсутствует |
| `OTKLIK_SMTP_USER` | Пользователь SMTP |
| `OTKLIK_SMTP_PASSWORD` | Пароль приложения или SMTP-пароль |

После настройки отправителя SMTP включается явной командой:

```sh
python3 -B mail_worker.py --database /path/to/database.sqlite3 --mode smtp
```

Команда выбирает только задания `transport='smtp'`. Переключение режима не отправляет локальные тестовые задания. Проверка настроек выполняется до захвата задания; при неполных настройках очередь остаётся нетронутой. TLS проверяет сертификат сервера, на сетевые операции установлен таймаут 15 секунд. Обработчик не запускается автоматически при открытии сайта. Расписание запуска пока не настроено.

## Состояния и повторы

`mail_queue.enqueue()` вызывается внутри транзакции бизнес-операции. Уникальный ключ события и отпечаток содержимого предотвращают повторную постановку одинакового письма. Изменённое письмо с прежним ключом отклоняется. Добавление в очередь не отправляет письмо и не фиксирует транзакцию за вызывающий код.

| Статус | Значение |
| --- | --- |
| `pending` | Ожидает обработки или безопасной повторной попытки |
| `sending` | Задание захвачено обработчиком на срок до 120 секунд |
| `sent` | SMTP-сервер подтвердил приём; доставка в ящик адресата не проверена |
| `preview` | Файл письма сформирован локально |
| `failed` | Окончательный отказ или исчерпаны безопасные повторы |
| `unknown` | Результат SMTP неизвестен, автоматический повтор запрещён |
| `cancelled` | Срок истёк либо задание отменено при восстановлении базы |

Одновременные обработчики захватывают задания транзакцией `BEGIN IMMEDIATE`. Захват имеет случайный идентификатор, чужой или просроченный обработчик не может перезаписать результат. SMTP выполняется после завершения транзакции захвата, без удержания блокировки базы на время сети.

Сбой соединения до передачи письма и явный временный отказ SMTP допускают повтор с задержкой от минуты, максимум шесть попыток. Потеря ответа во время передачи DATA считается неизвестным исходом. Задание не отправляется автоматически снова, даже если письмо могло не дойти. Остановка SMTP-обработчика с истёкшим захватом также переводит задание в `unknown`. Стабильный Message-ID не считается гарантией отсутствия дублей у получателя.

По умолчанию срок жизни задания семь дней; будущие операции подтверждения, восстановления и напоминаний должны задавать свой срок. Истёкшие ожидающие задания отменяются при обработке очереди, содержимое очищается. После успешного приёма SMTP, формирования локального файла или окончательного отказа получатель, тема и тело в строке очереди тоже очищаются. До обработки очередь содержит письмо, поэтому база и копии требуют закрытого доступа. Журнал не получает содержимое писем или текст исключений SMTP.

## Администратор и резервные копии

Обзор администратора показывает количества по статусам. Сводка не раскрывает адреса, тему, тело, ключ события и секретные ссылки. Через `--status` доступна безопасная сводка и последние 20 служебных состояний.

Миграция версии 7 в 8 создаёт `mail_outbox` и индекс. Перед обновлением существующей базы сохраняется копия. При пробном восстановлении базы незавершённые почтовые задания отменяются, содержимое очереди очищается. Исходная рабочая база остаётся прежней. Это исключает автоматическую отправку старых писем из восстановленной копии.

## Следующий шаг

Добавить одноразовые ссылки подтверждения адреса и восстановления пароля, необходимые формы и проверки доступа. Сначала проверить их с локальными `.eml`, затем подключить выбранный домен и SMTP-отправителя. Адрес администратора сейчас отсутствует; его восстановление автоматически на почту не переносится.
