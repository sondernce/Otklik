Два описания сохранены отдельно: их содержание различается.

Продолжаем разработку существующего приложения в `otklik/`: Python, SQLite, HTML, CSS и обычный JavaScript. Дорабатываем текущий сервер и интерфейс постепенно. Переход на Django и переписывание проекта не планируются. При расхождении исторических описаний с решениями в плане доработки используем план.
